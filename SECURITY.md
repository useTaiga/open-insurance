# Security reporting

Report vulnerabilities privately using [GitHub's vulnerability reporting form](https://github.com/useTaiga/open-insurance/security/advisories/new).

Include the affected commit, component, impact and a reproduction using fictional data. Do not include real patient records, private keys, production credentials, personal Wallet passes or diagnostic captures containing sensitive data. Maintainers can coordinate a minimal reproduction through the private report.

This project is a developer preview. The local lab and SQLite adapter are not production clinic access-control systems. Review the [architecture and deployment boundaries](docs/architecture.md) before integrating real member data.
