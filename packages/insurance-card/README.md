# Insurance card SDK

Issuer references, pass generation/signing, Stedi-shaped request composition, VAS decryption and an optional Bun SQLite store.

The [issuer onboarding guide](../../docs/issuer-onboarding.md) creates a runnable member portal and clinic resolver with setup diagnostics for Angle, Curative or Oscar.

Start with the [fictional issuer example](examples/issuer.ts) or read the [integration guide](../../docs/integration.md) for signing, persistence and contract generation. Run `bun run check` from the project root.
